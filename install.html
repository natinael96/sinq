Installing Sinq

Sinq is distributed as a signed APK from its releases page, not through an app store. Installing it takes three steps the first time, and none after that.

Before you start

  • Android 8.0 (Oreo) or newer. Older versions cannot install it.
  • About 60–90 MB of free space. The whole Bible, the lectionary and four Ethiopic typefaces ship inside the file.
  • No account, and no connection after the download. Nothing needs to be set up.

The three steps

  1. Download the APK

    Open the releases page and download the file named Sinq-v1.6.1.apk (or whatever the newest version number is) from the assets list.

    Go to the latest release

  2. Allow your browser to install apps

    Android blocks installs from outside the Play Store until you permit them, per app. When you open the downloaded file, Android will offer the setting directly, or find it yourself under Settings → Apps → Special app access → Install unknown apps, and turn it on for the browser or file manager you downloaded with.

  3. Open the file and install

    Tap the downloaded APK and confirm. Sinq opens with an introduction; the first thing worth doing is choosing your interface language and text size in Settings.

Permissions it will ask for

Only when you turn on a feature that needs them, and never for anything else:

Notifications
To show the prayer reminders you set. Asked the first time you enable one.
Exact alarms
So a prayer alarm rings at the hour you chose rather than whenever Android gets around to it.
Run at startup, and vibration
To re-arm your reminders after the phone restarts, and for the alarm's vibration.

There is no internet, location, camera, microphone, contacts or storage-scanning permission. The app does not have them to ask for. Full privacy policy.

If something goes wrong

“App not installed”
Usually there is already a copy of Sinq on the phone signed with a different key: one built from source, or from a very early release. Uninstall that copy first, then install the new APK. Your data is in that copy, so export a backup from Settings → Data before uninstalling.
“There was a problem parsing the package”
The download did not finish, or the file is not the APK. Only the file ending in .apk installs on a phone. Download it again, on a stable connection.
Play Protect warns about an unknown app
Expected. Google shows this for anything installed from outside the Play Store, whatever it contains. You can install anyway, or verify for yourself: the source is public and every release is built in the open by GitHub Actions from a tagged commit.
Reminders never arrive
Check that notifications and exact alarms are permitted for Sinq, that battery optimisation is not restricting it, and that the reminder is not scheduled inside your quiet hours. Sinq warns about that last one in Settings.

Anything else: open an issue.

Building it yourself

You need JDK 17 and the Android SDK (compileSdk 36). The content is bundled in the repository, so no content pipeline needs to run for a normal build.

git clone https://github.com/natinael96/sinq.git
cd sinq
./gradlew assembleDebug

The APK lands in app/build/outputs/apk/debug/. A build of your own is signed with your own key, so it will not install over a release copy and cannot be updated by one.
