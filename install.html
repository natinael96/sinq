Installing Sinqስንቅን መጫን

Sinq is distributed as a signed APK from its releases page, not through an app store. Installing it takes three steps the first time, and none after that. ስንቅ በመተግበሪያ መደብር ሳይሆን፣ ከዝማኔዎች ገጹ በተፈረመ APK ይሰራጫል። ለመጀመሪያ ጊዜ መጫኑ ሦስት ደረጃዎችን ይወስዳል፤ ከዚያ በኋላ ምንም።

Before you startከመጀመርዎ በፊት

  • Android 8.0 (Oreo) or newer. Older versions cannot install it.አንድሮይድ 8.0 (ኦሪዮ) ወይም ከዚያ በላይ። ከዚያ በታች ያሉት ስሪቶች መጫን አይችሉም።
  • About 60–90 MB of free space. The whole Bible, the lectionary and four Ethiopic typefaces ship inside the file.ከ60–90 ሜባ ገደማ ነጻ ቦታ። ሙሉው መጽሐፍ ቅዱስ፣ ግጻዌውና አራት የግእዝ ፊደላት በፋይሉ ውስጥ አሉ።
  • No account, and no connection after the download. Nothing needs to be set up.መለያ አያስፈልግም፤ ካወረዱ በኋላም ኢንተርኔት አያስፈልግም። ምንም ማዋቀር የለም።

The three stepsሦስቱ ደረጃዎች

  1. Download the APKAPK ያውርዱ

    Open the releases page and download the file named Sinq-v1.6.1.apk (or whatever the newest version number is) from the assets list.የዝማኔዎችን ገጽ ከፍተው Sinq-v1.6.1.apk የሚለውን ፋይል (ወይም አዲሱን የስሪት ቁጥር) ከዝርዝሩ ውስጥ ያውርዱ።

    Go to the latest releaseወደ አዲሱ ዝማኔ

  2. Allow your browser to install appsአሳሹ መተግበሪያ እንዲጭን ይፍቀዱ

    Android blocks installs from outside the Play Store until you permit them, per app. When you open the downloaded file, Android will offer the setting directly, or find it yourself under Settings → Apps → Special app access → Install unknown apps, and turn it on for the browser or file manager you downloaded with.አንድሮይድ ከፕሌይ ስቶር ውጭ የሚደረግ አጫጫንን እስከሚፈቀድለት ድረስ ይከለክላል፤ ለእያንዳንዱ መተግበሪያ ለብቻው። ያወረዱትን ፋይል ሲከፍቱ አንድሮይድ ራሱ ቅንብሩን ያቀርብልዎታል፤ ወይም ቅንብሮች → መተግበሪያዎች → ልዩ የመተግበሪያ መዳረሻ → ያልታወቁ መተግበሪያዎችን መጫን ውስጥ አግኝተው ላወረዱበት አሳሽ ወይም ፋይል አስተዳዳሪ ያብሩት።

  3. Open the file and installፋይሉን ከፍተው ይጫኑ

    Tap the downloaded APK and confirm. Sinq opens with an introduction; the first thing worth doing is choosing your interface language and text size in Settings.ያወረዱትን APK ነክተው ያረጋግጡ። ስንቅ በመግቢያ ይከፈታል፤ በመጀመሪያ የሚሻለው በቅንብሮች ውስጥ የመተግበሪያውን ቋንቋና የጽሑፍ መጠን መምረጥ ነው።

Getting updates automaticallyዝማኔን በራስ-ሰር ማግኘት

Because Sinq is not in an app store, nothing tells you when a new version appears. Obtainium solves this: it watches a project's releases page and prompts you when there is something newer. ስንቅ በመተግበሪያ መደብር ውስጥ ስለሌለ፣ አዲስ ስሪት ሲወጣ የሚነግርዎት የለም። Obtainium ይህንን ይፈታል፦ የፕሮጀክቱን የዝማኔዎች ገጽ ይከታተልና አዲስ ሲኖር ያሳውቅዎታል።

Install Obtainium, add an app, and paste this address:Obtainium ን ይጫኑ፣ መተግበሪያ ይጨምሩ፣ ይህንን አድራሻ ይለጥፉ፦

https://github.com/natinael96/sinq

Why an update from a stranger's file is still safe. Every release is signed with the same key. Android refuses to install an update over an existing app unless the signature matches, so a tampered or impersonating APK cannot replace your copy of Sinq. It simply fails to install. ዝማኔው ለምን አስተማማኝ እንደሆነ። እያንዳንዱ ዝማኔ በተመሳሳይ ቁልፍ ተፈርሟል። አንድሮይድ ፊርማው ካልተመሳሰለ በነባሩ መተግበሪያ ላይ ዝማኔ እንዲጫን አይፈቅድም፤ ስለዚህ የተቀየረ ወይም የተመሰለ APK የእርስዎን ስንቅ ሊተካ አይችልም። በቀላሉ አይጫንም።

Permissions it will ask forየሚጠይቃቸው ፈቃዶች

Only when you turn on a feature that needs them, and never for anything else:የሚጠይቀው የሚያስፈልጋቸውን ባህሪያት ሲያበሩ ብቻ ነው፤ ለሌላ ምንም ነገር አይደለም፦

Notificationsማሳወቂያዎች
To show the prayer reminders you set. Asked the first time you enable one.እርስዎ ያዘጋጇቸውን የጸሎት አስታዋሾች ለማሳየት። ለመጀመሪያ ጊዜ ሲያበሩ ይጠየቃል።
Exact alarmsትክክለኛ ማንቂያዎች
So a prayer alarm rings at the hour you chose rather than whenever Android gets around to it.የጸሎት ማንቂያው አንድሮይድ በፈለገው ጊዜ ሳይሆን፣ እርስዎ በመረጡት ሰዓት እንዲጮህ።
Run at startup, and vibrationበማስነሻ ላይ መሮጥና ንዝረት
To re-arm your reminders after the phone restarts, and for the alarm's vibration.ስልኩ ከተነሳ በኋላ አስታዋሾችዎን መልሶ ለማዘጋጀት፣ እንዲሁም ለማንቂያው ንዝረት።

There is no internet, location, camera, microphone, contacts or storage-scanning permission. The app does not have them to ask for. Full privacy policy. የኢንተርኔት፣ የአካባቢ፣ የካሜራ፣ የማይክሮፎን፣ የእውቂያ ወይም የማከማቻ ፍተሻ ፈቃድ የለም። መተግበሪያው እነዚህን የሚጠይቅበት ፈቃድ ራሱ የለውም። ሙሉውን የግላዊነት ፖሊሲ።

If something goes wrongችግር ካጋጠመ

“App not installed”“መተግበሪያው አልተጫነም”
Usually there is already a copy of Sinq on the phone signed with a different key: one built from source, or from a very early release. Uninstall that copy first, then install the new APK. Your data is in that copy, so export a backup from Settings → Data before uninstalling.ብዙውን ጊዜ በስልኩ ላይ በተለየ ቁልፍ የተፈረመ ሌላ የስንቅ ቅጂ አለ፤ ከምንጭ ኮድ የተገነባ ወይም በጣም ቀደም ያለ ስሪት። መጀመሪያ ያንን ያራግፉ፤ ከዚያ አዲሱን APK ይጫኑ። መረጃዎ በዚያ ቅጂ ውስጥ ስለሆነ፣ ከማራገፍዎ በፊት ከቅንብሮች → መረጃ ምትኬ ያውጡ።
“There was a problem parsing the package”“ጥቅሉን በማንበብ ላይ ችግር ተፈጥሯል”
The download did not finish, or the file is not the APK. Only the file ending in .apk installs on a phone. Download it again, on a stable connection.ማውረዱ አልተጠናቀቀም፣ ወይም ፋይሉ APK አይደለም። በስልክ ላይ የሚጫነው በ.apk የሚያልቀው ፋይል ብቻ ነው። በተረጋጋ ግንኙነት እንደገና ያውርዱት።
Play Protect warns about an unknown appPlay Protect ስለማይታወቅ መተግበሪያ ሲያስጠነቅቅ
Expected. Google shows this for anything installed from outside the Play Store, whatever it contains. You can install anyway, or verify for yourself: the source is public and every release is built in the open by GitHub Actions from a tagged commit.የሚጠበቅ ነው። ጉግል ይህንን ከፕሌይ ስቶር ውጭ ለተጫነ ማንኛውም ነገር ያሳያል፤ ይዘቱ ምንም ይሁን ምን። ቢሆንም መጫን ይችላሉ፤ ወይም ራስዎ ያረጋግጡ፦ ኮዱ ይፋ ነው፤ እያንዳንዱ ዝማኔም በGitHub Actions ከታተመ ኮድ በግልጽ ይገነባል።
Reminders never arriveአስታዋሾች ካልደረሱ
Check that notifications and exact alarms are permitted for Sinq, that battery optimisation is not restricting it, and that the reminder is not scheduled inside your quiet hours. Sinq warns about that last one in Settings.ለስንቅ ማሳወቂያዎችና ትክክለኛ ማንቂያዎች መፈቀዳቸውን፣ የባትሪ ቁጠባ እያገደው አለመሆኑን፣ አስታዋሹም በጸጥታ ሰዓትዎ ውስጥ አለመመደቡን ያረጋግጡ። የመጨረሻውን ስንቅ ራሱ በቅንብሮች ውስጥ ያስጠነቅቃል።

Anything else: open an issue.ሌላ ማንኛውም ነገር፦ ጉዳይ ይክፈቱ።

Building it yourselfራስዎ መገንባት

You need JDK 17 and the Android SDK (compileSdk 36). The content is bundled in the repository, so no content pipeline needs to run for a normal build.JDK 17 እና የAndroid SDK (compileSdk 36) ያስፈልጋሉ። ይዘቱ በማከማቻው ውስጥ አብሮ ስላለ፣ ለተለመደ ግንባታ ምንም ተጨማሪ ሂደት ማስኬድ አያስፈልግም።

git clone https://github.com/natinael96/sinq.git
cd sinq
./gradlew assembleDebug

The APK lands in app/build/outputs/apk/debug/. A build of your own is signed with your own key, so it will not install over a release copy and cannot be updated by one.APK-ው app/build/outputs/apk/debug/ ውስጥ ይቀመጣል። የራስዎ ግንባታ በራስዎ ቁልፍ ስለሚፈረም፣ በተለቀቀው ቅጂ ላይ አይጫንም፤ በእሱም አይዘመንም።
